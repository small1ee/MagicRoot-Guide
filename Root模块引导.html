临时 root 诊断

① 你的 su 管理器分支

不确定？先回答两个问题，或直接下拉手动选择。

② 安装清单

三条互斥铁律
1. 一个内核只能有一套 root：Magisk / KernelSU / APatch 不能共存。
2. 管理器与内核必须同分支同版本协议，跨分支 = 显示「未安装 / 不支持」。
3. Zygisk 实现只能有一套：内置引擎与外挂二选一，双开会抢注入。

动手前：先备份 A/B 双槽 init_boot、abl、GPT 并导出到电脑；一次只改一个变量，改完重启验证，出问题立刻回退。

① 复制诊断脚本，在手机上跑一遍

脚本只读，不修改任何系统状态，可放心运行。两条路任选：
A（推荐）：存成 rootdiag.sh → adb push rootdiag.sh /data/local/tmp/ → adb shell "su -c 'sh /data/local/tmp/rootdiag.sh'"
B：直接在手机上的终端 App（或管理器的终端）里粘贴执行。
临时 root 场景下，每次开机都要重新提权。诊断前先确认提权工具已跑通，否则第一步就会显示没有 root。

② 把输出整段粘回来
